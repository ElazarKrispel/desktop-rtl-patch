2. [תכנית ביצוע מפורטת](IMPLEMENTATION-PLAN.he.md): שלב 0 לאימות עצמאי; חבילות A–F; תלויות, תנאי קבלה, שערי החלטה, חלוקת עבודה ו־Definition of Done. זהו פירוט אופרטיבי של המלצות הדוח, לא דיווח שהן מומשו.
3. [פנקס אימות ומעקב](VALIDATION-REGISTER.he.md): תור עבודה מלא ל־F01–F10 עם סוגי ראיה, בדיקות חסרות והגדרת סגירה. אף ממצא לא מסומן כתיקון שהושלם.
4. [הקשר והמשך חקירה](REVIEW-NOTES.he.md): ההבחנה בין התכנון הישן לקוד הנוכחי, שאלות שהקוד העלה ואינן מאומתות ב־Windows, והחלטות פתוחות. הפרק אינו מרחיב בשקט את מספר הממצאים המאומתים.
5. [ראיות השחזור המקוריות](rtl-review-evidence/README.md): פונקציה שחולצה מן ה־commit שנבדק, probe על קבצים זמניים בלבד ותוצאת JSON. זו בדיקת Linux/Node, לא בדיקת Windows מקצה לקצה.
6. [מקוריות ובדיקות החבילה](PROVENANCE.json): זהות המקור, hashes, בדיקות שבוצעו ומגבלות.

## ההחלטה המומלצת

**להמשיך לפתח ולהפיץ באופן מבוקר: הקשחה → בטא מוגדרת → מנהל Windows עצמאי → הרחבות לפי ביקוש.**

לא להתחיל בשכתוב כולל ולא להסיק ש־framework חדש יפתור מסלולי הסרה, state או נתונים. ההמלצה למנהל C# / .NET / WPF היא הצעת ארכיטקטורה לבחינה; Tauri היא חלופה לגיטימית. קוד וראיות עדכניים גוברים על העדפת הסטאק בדוח.

## מה החבילה כן ולא מוכיחה

הדוח משמר ממצאי סקירת קוד ומקורות שנאספו. ה־main שנקרא בזמן הכנת החבילה עדיין הצביע ל־baseline של הסקירה. יש לבדוק מחדש אם הריפו מתקדם לאחר מכן.

בדיקת F01 המצורפת חזרה על אותה תוצאה בסביבת Linux / Node v22.16.0: יעד חיצוני ישיר נדחה; יעד פיזי חיצוני דרך קישור מתוך root שונה. כל הקבצים היו fixtures זמניים. אין כאן הוכחת privilege escalation, בדיקת junction ב־Windows או אישור שכל שרשרת ההתקנה פגיעה.

Windows PowerShell 5.1, האשף, המגש והאפליקציות האמיתיות לא הורצו במסגרת הסקירה או הכנת ה־PR. ה־ZIP של release המוצר לא אומת מחדש byte-for-byte. בדיקות שהמפתח דיווח עליהן ב־PR קודם אינן מוצגות כאילו הורצו על ידי הסוקר.

## הוראות עבודה ל־ASTRA

לקרוא את הקבצים המלאים ואת הקוד שאליו הם מפנים, לא רק את תיאור ה־PR. להתחיל בשלב 0, לעדכן את הפנקס עם ראיות ולהציע רצף PRים. מותר להפריך ממצא או להציע פתרון טוב יותר; צריך להסביר זאת ולשמור traceability.

לא לשנות קוד מוצר במסגרת PR התיעוד; לא למזג אותו אוטומטית; לא להתחיל שכתוב GUI, להתקין מקור מחדש, למחוק פרופילים או לפרסם גרסה בלי אישור מתאים. תכנית מפורטת אינה הרשאה לבצע כל פעולה המוזכרת בה.
