# פרסום חבילת האימות

החבילה מתעדת את האימות העצמאי שנערך ב־7 בספטמבר 2026. היא נשמרת בנפרד מ[הסקירה המקורית ב־PR #8](https://github.com/ElazarKrispel/desktop-rtl-patch/pull/8). קוד המוצר שנבדק הוא `02cc70a8b750de4bc88b740cf8a64f292a5c0325`; ראש חומר הסקירה שנקרא הוא `3c48cc43514d70137706fa257902008822dc6a8e`.

ה־PR הזה כולל רק מסמכים, קוד שיוצר fixtures מינימליים בזמן הרצה ותוצאות מסוננות. אין בו תיקיות fixture שנוצרו, פרופילי דפדפן, נתוני משתמש, בינארים של אפליקציות או ZIP של release. לא שונה קוד מוצר. אמירות במסמכי האימות על העדר commit/פרסום משקפות את סוף שלב האימות, לפני האישור לפרסום החבילה ב־8 בספטמבר.

תחילת הקריאה: [חוות הדעת](README.he.md), [פנקס האימות](VALIDATION.he.md), [תכנית PRים](PR-PLAN.he.md), [החלטות ארכיטקטורה](ARCHITECTURE-DECISIONS.he.md), [פנקס הרצות](TEST-REGISTER.he.md).

כל תוצאה מבחינה בין Windows filesystem אמיתי ב־fixture, גופי פונקציות שחולצו ב־AST, גבולות מערכת מדומים והרצת payload אמיתי ב־DOM סינתטי. התקנות/הסרות מקור, GUI/tray חי, Registry אמיתי, named events של המוצר ונתוני פרופיל אמיתי לא הופעלו. NOT RUN/BLOCKED נשארים מפורשים. אין בחבילה אישור E2E או אישור להפצה.

## שחזור מתוך clone אחר

הפקודות המלאות בפנקס ההרצות. לבדיקת מקוריות חומר PR #8 יש להביא את הענף המקורי, ללא מיזוג:

```powershell
git fetch origin docs/release-readiness-review-2026-09-07
```

קוד הבדיקות קורא קוד מוצר מ־checkout מקומי. יש להריץ כנגד ה־baseline המוצהר, לא נגד קוד תיקון חדש ולפרש כשל assertion כבדיקת קבלה. כמה probes דורשים Windows, PowerShell 5.1, Node 24 או Chrome מקומי. בדיקת ה־ZIP דורשת הורדה מפורשת של assets, ואינה מריצה אותם. paths מקומיים במסמכי הראיות הם מיקומי הבדיקה ההיסטוריים; אין צורך בתיקיות המקור הסינתטיות לשחזור, כי scripts יוצרים fixtures חדשים.

המחיקות האוטומטיות שנדחו בשלב האימות לא נוסו שוב. התיקיות הישנות נשארו בעץ העבודה המקומי ומוחרגות ב־.gitignore. אין לנקות אותן כחלק מפקודת השחזור או לעקוף את הדחייה.
